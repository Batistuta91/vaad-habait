# 🏠 מערכת ניהול ועד בית

מערכת ניהול מלאה לוועד בית – Node.js + Express + EJS

---

## 🚀 התקנה והפעלה

```bash
# 1. כניסה לתיקייה
cd vaad-habait

# 2. התקנת תלויות
npm install

# 3. הפעלת השרת
npm start
```

השרת יעלה על: **http://localhost:3000**

---

## 🔗 כתובות

| ממשק | כתובת | סיסמה |
|------|-------|-------|
| דיירים | http://localhost:3000 | מספר דירה + סיסמת דייר (ברירת מחדל: 1234) |
| מנהל | http://localhost:3000/admin | admin123 |

## 🔧 מודולים

### 1. ניהול דיירים
- הוספה/עריכה/מחיקה של 20 דירות
- סיסמה ייעודית לכל דייר
- סימון דירות בשכירות + פרטי בעל נכס

### 2. גבייה שוטפת
- רישום תשלומים לפי חודש ושנה
- תשלום מראש למספר חודשים
- הפקת קבלות דיגיטליות
- ביטול תנועה (צ'ק חזר)

### 3. המחאות דחויות
- רישום צ'קים דחויים קדימה
- הזנה חכמה של מספר חודשים
- מעקב תאריכי פירעון

### 4. גבייה חד-פעמית
- פרויקטים מיוחדים (אינטרקום, זיפות וכו')
- ויזואליזציית שבבי תשלום לכל דירה
- מד התקדמות גבייה

### 5. ספקים ועסקאות שירות
- ניהול ספקים לפי מקצוע
- מעקב תכנון מול ביצוע
- רישום תשלומים לספקים

### 6. דשבורד מנהל
- יתרה כוללת בקופה
- דיירים עם חובות
- צ'קים קרובים לפירעון
- ייצוא CSV

### 7. ממשק דייר
- אזור אישי עם מצב חשבון
- טבלת שקיפות ציבורית
- פרטי תשלום + Paybox
